# Task 1: Create UI Policy on Incident

## Activity 1: Create UI Policy

1. Log in to the ServiceNow instance with administrative or configuration access.

2. Navigate to:
   All → System UI → UI Policies

3. Click on:
   New

4. Select the table:
   Incident [incident]

5. Enter the required UI Policy details.

6. Define the condition according to the business requirement.

7. Configure the required UI Policy Actions.

8. Save the UI Policy.

## Expected Result

The UI Policy should dynamically control the Incident form fields based on the defined condition.

## Testing

Open an Incident record and verify that the configured field behavior works correctly.

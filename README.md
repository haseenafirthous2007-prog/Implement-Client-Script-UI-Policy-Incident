# Implement Client Script & UI Policy (Incident)

## Problem Statement

Incident records require consistent and accurate data entry.
UI Policies and Client Scripts help control field behavior,
validation, and mandatory fields in ServiceNow.

## Objective

The objective of this project is to implement Client Scripts
and UI Policies on Incident records to improve data accuracy
and enforce business rules.

# Task 2: Configure UI Policy Actions

## Activity 1: Create UI Policy Action

1. Open the UI Policy created for the Incident table.

2. Scroll down to the UI Policy Actions section.

3. Click on:
   New

4. Select the required Incident field.

5. Configure the field behavior:
   - Mandatory
   - Visible
   - Disabled

6. Set the required values according to the business requirement.

7. Save the UI Policy Action.

## Expected Result

The selected Incident fields should automatically change their behavior when the UI Policy condition is satisfied.

## Testing

Open an Incident record and change the field value required for the UI Policy condition.

Verify that the configured fields become mandatory, visible, or disabled as specified.
